    __init__.py - mentions python folder
    asgi.py - asychronous gateway interface
    settings.py - project's configuration
    urls.py - connects url to functions
    wsgi.py - web server gateway interface

App Folder 
    Specific Feature

    migrations/ - saves the models changes
    models.py - py file connects to db
    admin.py - configures admin dashboard
    apps.py - app's configuration
    tests.py - helps for testing
    views.py - file that makes logic 

db.sqlite3 - django default db
manage.py - entry point of django
